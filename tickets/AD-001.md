# AD-001 — Remove Workstation from Active Directory Domain

## Ticket Overview

| Field | Details |
|---|---|
| Ticket ID | `AD-001` |
| Category | Active Directory / Workstation Management |
| Type | Service Request |
| Priority | Low |
| Affected System | WIN1 |
| Status | Resolved |
| Tools Used | System Properties (`sysdm.cpl`), local administrator account, ADUC |

## 1. Issue Description

A  workstation needed to be removed from the `lab.local` domain as part of an offboarding or decommissioning simulation.

Jira Ticket:

<img width="1461" height="387" alt="image" src="https://github.com/user-attachments/assets/18580e1d-7d1d-4af6-be5e-21ac6ec7bc47" />



**Expected behavior:** WIN1 leaves the domain and remains accessible using a local administrator account.

**Observed behavior:** WIN1 is currently part of the domain and remains accessible using a domain account.

## 2. Investigation and Troubleshooting

1. Checked how domain membership is changed through `sysdm.cpl`.
2. Identified the need for administrator elevation and a working local administrator account before removal.
3. Confirmed that the Windows client had local accounts available; the built-in Administrator account was disabled.
4. Distinguished removing the machine from the domain from separately deleting or disabling its AD computer object.

## 3. Root Cause / Request Context

Not applicable — planned workstation domain removal is a service request.

## 4. Resolution / Action Taken

1. Opened System Properties using `sysdm.cpl`.
2. Used the computer-name/domain membership settings to leave `lab.local` and switch to a workgroup.
   
   <img width="531" height="558" alt="image" src="https://github.com/user-attachments/assets/4cdf0672-e2c3-426d-bfa6-6cbb8bcf65e5" />

3. Provided administrator credentials where required.
   
   <img width="556" height="667" alt="image" src="https://github.com/user-attachments/assets/1f0d1c9c-650a-48f7-9271-03e86ebff209" />

4. Restarted the workstation to apply the change.

## 7. Key Takeaways

Before unjoining a workstation, verify local administrator access to avoid locking yourself out. Removing domain membership and cleaning up the directory object are distinct tasks.
