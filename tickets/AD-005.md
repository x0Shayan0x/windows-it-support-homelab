# AD-005 — Unlock Locked Active Directory Account

## Ticket Overview

| Field | Details |
|---|---|
| Ticket ID | `AD-005` |
| Category | Active Directory / Account Support |
| Type | Incident |
| Priority | Low |
| Affected System | Test domain user |
| Status | Resolved |
| Tools Used | Active Directory Users and Computers, PowerShell |

## 1. Issue Description

A test domain user was unable to sign in because the account was locked.

Jira Ticket:

<img width="1837" height="335" alt="image" src="https://github.com/user-attachments/assets/ebb3c4ce-eb2e-48f0-9e12-4ad3098efd4a" />


**Expected behavior:** Once the lockout is cleared and the underlying cause addressed, the user can authenticate normally.

**Observed behavior:** The user is able to re-gain access to their account.

## 2. Investigation and Troubleshooting

1. Located the affected account in Active Directory Users and Computers.
2. Checked the account’s locked/unlocked state.
3. Reviewed the domain’s lockout behavior and the delay associated with lockout testing.

**Example verification command:**

```powershell
Get-ADUser -Identity pjohnson -Properties LockedOut | Select Name, SamAccountName, LockedOut
```

## 3. Root Cause / Request Context

The account entered a locked state due to a number of incorrect password attempts.

## 4. Resolution / Action Taken

1. Located the test account in ADUC.
2. Used the account unlock option.

   <img width="407" height="555" alt="image" src="https://github.com/user-attachments/assets/83c76475-0a39-4eac-a8bb-deef6b29106d" />

3. Checked the account state after the change.

## 5. Verification

- The account-unlock exercise was completed.
- Final `LockedOut` attribute output of `Get-ADUser -Identity pjohnson -Properties LockedOut | Select Name, SamAccountName, LockedOut` returned true.
