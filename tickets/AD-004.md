# AD-004 — Reset Active Directory User Password

## Ticket Overview

| Field | Details |
|---|---|
| Ticket ID | `AD-004` |
| Category | Active Directory / Account Support |
| Type | Service Request |
| Priority | Low |
| Affected System | Test domain user |
| Status | Resolved |
| Tools Used | Active Directory Users and Computers, PowerShell |

## 1. Issue Description

A test employee requested a password reset for their Active Directory account.

Jira Ticket:

<img width="1852" height="327" alt="image" src="https://github.com/user-attachments/assets/13742a7b-4120-4c61-acab-1f002c72a981" />


**Expected behavior:** An authorized technician resets the password, and the user can sign in using the newly issued temporary credential.

**Observed behavior:** The user cannot progress past the sign-in page.

## 2. Investigation and Troubleshooting

1. Located the relevant user account in Active Directory Users and Computers.
2. Reviewed the domain password-policy settings and the password-reset workflow.

## 3. Root Cause / Request Context

Not applicable — a password-reset request does not necessarily indicate a system fault.

## 4. Resolution / Action Taken

1. Selected the test user in Active Directory Users and Computers.
2. Used **Reset Password** and applied a lab-compliant temporary password.

   <img width="375" height="255" alt="image" src="https://github.com/user-attachments/assets/fd8ea2d4-4bd4-4083-abc9-08c1d453080f" />

3. Reviewed whether the user should change the password at the next sign-in.


## 5. Verification

- The password-reset exercise was completed.
- The user was able to login and reset their password

Password resets require identity verification in a real organization. Support staff should never ask users to disclose their existing passwords.
