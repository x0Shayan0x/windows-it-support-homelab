# NET-001 — Incorrect DNS Server Configuration

## Ticket Overview

| Field | Details |
|---|---|
| Ticket ID | `NET-001` |
| Category | Networking / DNS |
| Type | Incident |
| Priority | Medium |
| Affected System | WIN1 |
| Status | Resolved |
| Tools Used | Command Prompt, `ipconfig`, `nslookup`, `nltest`, Windows adapter settings |

## 1. Issue Description

A test workstation was configured with an incorrect DNS resolver, affecting discovery of internal Active Directory services.

Jira Ticket:

<img width="1837" height="425" alt="image" src="https://github.com/user-attachments/assets/b18ad375-0e1f-4ffa-95f5-ae1a4cafd377" />


**Expected behavior:** WIN1 uses the internal DNS server `192.168.56.10` to resolve `lab.local` records.

**Observed behavior:** The client was pointed at an external DNS resolver (`8.8.8.8`) rather than the domain DNS server.

## 2. Investigation and Troubleshooting

1. Examined the workstation network settings with `ipconfig /all`.

   <img width="762" height="560" alt="image" src="https://github.com/user-attachments/assets/587c9c81-0c51-4fb5-a917-02298d474605" />

2. Compared the configured DNS address with the expected internal DNS server `192.168.56.10`.

3. Made sure the Domain Server was still reachable with the ping command to isolate the issue to incorrect DNS configuration

   <img width="502" height="228" alt="image" src="https://github.com/user-attachments/assets/486ea806-4aa7-4c2f-a78b-a36edc55e3fe" />


## 3. Root Cause / Request Context

WIN1 was using a DNS resolver that did not host the internal Active Directory DNS zone, preventing reliable resolution of domain-specific service records.

## 4. Resolution / Action Taken

1. Opened the Windows network adapter’s IPv4 properties.
2. Replaced the incorrect DNS server with the lab domain DNS server, `192.168.56.10`.

   <img width="397" height="452" alt="image" src="https://github.com/user-attachments/assets/4894efd5-efb1-4978-ad57-1d8bffb0b47d" />

3. Flushed the incorrect DNS IP Address cache

   <img width="447" height="103" alt="image" src="https://github.com/user-attachments/assets/c29602ec-b3d3-4d28-9645-785adf9320e3" />
